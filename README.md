# PrepZero

**Buy it. Cook it. Divide it. Done.**

PrepZero is a food-efficiency app concept focused on helping people hit their nutrition targets with less waste, less cost and less time in the kitchen.

## Product principles

- Hit calorie and protein targets first
- Prefer real supermarket pack sizes
- Minimise unused food
- Minimise cooking sessions
- Avoid unnecessary weighing and measuring
- Keep meals nutritious, filling and enjoyable

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Stack

- Next.js
- React
- TypeScript
- Plain responsive CSS

The current branch contains the initial responsive landing-page concept only. The optimiser, onboarding flow, data model and authentication are intentionally not part of this first design pass.
